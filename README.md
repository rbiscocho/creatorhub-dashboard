# CreatorHub – Content Creator Agency Resource Booking Dashboard

A modern, dark-themed HTML dashboard for managing creator bookings, talent, clients, and reports.

## Live Demo

**GitHub Pages:** https://rbiscocho.github.io/creatorhub-dashboard/

## Pages

| Page | File | Description |
|------|------|-------------|
| Dashboard | `dashboard.html` | Overview with stats, upcoming bookings & creator availability |
| Bookings | `bookings.html` | Full booking list with filters |
| Creators | `creators.html` | Talent cards with rates & availability |
| Clients | `clients.html` | Brand / client management table |
| Reports | `reports.html` | Revenue analytics & top performers |
| Settings | `settings.html` | Agency profile, notifications, booking rules, team |

## How to use

1. Open any `.html` file in a browser, or
2. Visit the GitHub Pages link above.

## Tech

- Pure HTML + CSS (no frameworks)
- Dark modern UI
- Responsive layout
- Sample data for a content creator agency

Built for content creator agencies to manage talent bookings.
